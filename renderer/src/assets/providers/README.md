# Logos dos serviços de IA

Imagens usadas só para **identificar** cada serviço em Configurações > IAs externas
(`components/ProviderLogo.tsx`). Redimensionadas para 128 px; sem outra alteração.

| Arquivo | Serviço | Origem |
|---|---|---|
| `gemini.png` | Google Gemini | `google-gemini.png` do repositório Dashboard Icons (homarr-labs/dashboard-icons), que reúne os ícones do LobeHub (licença MIT) |
| `anthropic.png` | Anthropic | `claude-ai.png` do mesmo repositório (marca "A" da Anthropic) |
| `groq.png` | Groq | `light/groq.png` do pacote `@lobehub/icons-static-png` (LobeHub, licença MIT) |

A licença MIT vale para os arquivos do repositório. As **marcas** continuam sendo das empresas
(Google e Anthropic), que têm regras próprias de uso; a Anthropic pede aprovação prévia para usar
os logos dela (https://www.anthropic.com/legal/trademark-guidelines). Para trocar por um arquivo
oficial, substitua o PNG mantendo o nome.
